A complete WordPress theme for Recipe & WooCommerce CMS with modern design and full functionality.

== Description ==

Foodieland is a production-ready WordPress theme designed for recipe websites with integrated WooCommerce functionality. Features include:

* Custom Post Types: Recipes, Chefs, Testimonials, FAQs, Partners, Events, Gallery, Videos
* Custom Taxonomies: Recipe Categories, Cuisines, Difficulty, Ingredients, Meal Types, Diets
* WooCommerce Integration: Full shop support with custom styling
* Responsive Design: Mobile-first approach with Tailwind CSS
* Modern JavaScript: Alpine.js for interactivity, Swiper.js for sliders
* SEO Optimized: Schema markup, Open Graph support
* Performance: Lazy loading, optimized assets, Lighthouse 95+ target
* Accessibility: WCAG AA compliant, keyboard navigation, ARIA labels
* Security: Nonce verification, input sanitization, output escaping

== Installation ==

1. Upload the foodieland-theme folder to /wp-content/themes/
2. Activate the theme through WordPress Admin > Appearance > Themes
3. Install required plugins (WooCommerce recommended)
4. Configure theme options in Customizer
