# Foodieland WordPress CMS + WooCommerce Requirements

## Project Overview

Build a **production-ready WordPress CMS and WooCommerce e-commerce
website** inspired by the provided Foodieland UI. The final product must
be a fully dynamic, responsive, SEO-optimized website with a custom
WordPress theme.

## Goals

-   Custom WordPress theme (no Elementor/WPBakery)
-   WooCommerce integration
-   Dynamic CMS
-   Responsive design
-   Modern UI matching the provided templates
-   Performance, accessibility, and security best practices

## Tech Stack

-   WordPress (latest)
-   PHP 8.3+
-   WooCommerce
-   Tailwind CSS
-   SCSS
-   Alpine.js
-   Swiper.js
-   MySQL
-   REST API
-   Gutenberg Blocks
-   Optional: ACF
